Publishing an epoch

  1. make multiasset-prices REGISTRY=0x… Pull the conversion table and oracle round ids from the registry.
  2. make multiasset-fixtures Build the witness and each customer's inclusion proof from the ledger.
  3. make multiasset-prove Generate and locally verify the zero-knowledge proof.
  4. make multiasset-demo Submit on-chain. The contract re-reads the pinned rounds, verifies the proof against them, values the reserves and rejects the epoch unless they cover the liabilities.
