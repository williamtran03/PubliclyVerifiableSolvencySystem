Publishing an epoch

  1. make zk-snapshot REGISTRY=0x… Read the epoch context, approved reserves, prices and oracle round ids from the registry.
  2. make zk-fixtures Build the witness and each customer's inclusion proof, with the reserves as floors.
  3. make zk-prove Generate and locally verify the zero-knowledge proof.
  4. make zk-demo Submit on-chain. The contract checks reserves cover every floor, verifies the proof for this epoch, and records the USD value at the pinned rounds.
